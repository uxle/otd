# Fun facts about Manganese

Deep-sea nodules of manganese grow 1 cm per million years.

More angles on the same element:
- atomic number 25 — in a periodic table sorted by Z, Mn is entry #25
- one mole (54.938 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.21 g — sample 31 is exactly this cube
- its melting point 1246 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
