# Physical properties of Manganese

| property | value |
|---|---|
| density (near room temp) | 7.21 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1246 °C |
| boiling point | 2061 °C |
| appearance | see 09-optical-properties.md — colour #9c7ac7 in this library's palette |

Density is mass divided by volume: a cube of Manganese measuring 1 cm on a side
weighs 7.21 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Manganese is a solid at room temperature; heat it past 1246 °C and it flows.
