# Fun facts about Zinc

Your body uses zinc in over 300 enzymes — taste and immunity need it.

More angles on the same element:
- atomic number 30 — in a periodic table sorted by Z, Zn is entry #30
- one mole (65.38 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.14 g — sample 31 is exactly this cube
- its melting point 419.5 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
