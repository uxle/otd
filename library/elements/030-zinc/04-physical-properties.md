# Physical properties of Zinc

| property | value |
|---|---|
| density (near room temp) | 7.14 g/cm³ |
| phase at 20 °C | solid |
| melting point | 419.5 °C |
| boiling point | 907 °C |
| appearance | see 09-optical-properties.md — colour #7d80b0 in this library's palette |

Density is mass divided by volume: a cube of Zinc measuring 1 cm on a side
weighs 7.14 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Zinc is a solid at room temperature; heat it past 419.5 °C and it flows.
