# Fun facts about Ruthenium

Ruthenium hardens pen tips — the ball of a good pen can outlive its ink.

More angles on the same element:
- atomic number 44 — in a periodic table sorted by Z, Ru is entry #44
- one mole (101.07 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 12.45 g — sample 31 is exactly this cube
- its melting point 2334 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
