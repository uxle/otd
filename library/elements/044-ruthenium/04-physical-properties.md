# Physical properties of Ruthenium

| property | value |
|---|---|
| density (near room temp) | 12.45 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2334 °C |
| boiling point | 4150 °C |
| appearance | see 09-optical-properties.md — colour #a0c0c0 in this library's palette |

Density is mass divided by volume: a cube of Ruthenium measuring 1 cm on a side
weighs 12.45 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Ruthenium is a solid at room temperature; heat it past 2334 °C and it flows.
