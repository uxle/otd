# Physical properties of Silicon

| property | value |
|---|---|
| density (near room temp) | 2.329 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1414 °C |
| boiling point | 3265 °C |
| appearance | see 09-optical-properties.md — colour #f0c8a0 in this library's palette |

Density is mass divided by volume: a cube of Silicon measuring 1 cm on a side
weighs 2.329 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Silicon is a solid at room temperature; heat it past 1414 °C and it flows.
