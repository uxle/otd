# Mechanical properties of Silicon

| aspect | note for Silicon |
|---|---|
| density | 2.329 g/cm³ — used for honest mass in every sample |
| typical hardness | moderate to hard |
| typical strength | metals deform (ductile); nonmetals fracture (brittle) |
| compressive character | solids carry load until they yield or crack |

## Engineering view
Silicon is a metalloid. Mechanical designers care about four numbers —
yield strength, ultimate strength, stiffness (Young's modulus) and toughness.
This library does not pretend to tabulate all four for every element; instead
every 3D sample carries the true density, so weight-dependent physics (drop
energy, buoyancy, collapse stress) is computed from real mass.

Archimedes' verdict for Silicon in water: density 2.329 g/cm³
≥ 1.00 — it sinks.
