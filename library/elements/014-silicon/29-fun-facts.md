# Fun facts about Silicon

A silicon wafer is 99.9999999% pure silicon — nine nines, one stray atom per billion.

More angles on the same element:
- atomic number 14 — in a periodic table sorted by Z, Si is entry #14
- one mole (28.085 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 2.329 g — sample 31 is exactly this cube
- its melting point 1414 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
