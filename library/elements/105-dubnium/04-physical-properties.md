# Physical properties of Dubnium

| property | value |
|---|---|
| density (near room temp) | 29.3 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2200 °C |
| boiling point | 5500 °C |
| appearance | see 09-optical-properties.md — colour #60c0ff in this library's palette |

Density is mass divided by volume: a cube of Dubnium measuring 1 cm on a side
weighs 29.3 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Dubnium is a solid at room temperature; heat it past 2200 °C and it flows.
