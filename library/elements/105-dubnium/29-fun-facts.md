# Fun facts about Dubnium

Dubnium honours the Russian lab that raced Berkeley to the superheavy elements.

More angles on the same element:
- atomic number 105 — in a periodic table sorted by Z, Db is entry #105
- one mole (268.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 29.3 g — sample 31 is exactly this cube
- its melting point 2200 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
