# Physical properties of Rhodium

| property | value |
|---|---|
| density (near room temp) | 12.41 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1964 °C |
| boiling point | 3695 °C |
| appearance | see 09-optical-properties.md — colour #c0c0c0 in this library's palette |

Density is mass divided by volume: a cube of Rhodium measuring 1 cm on a side
weighs 12.41 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Rhodium is a solid at room temperature; heat it past 1964 °C and it flows.
