# Physical properties of Neptunium

| property | value |
|---|---|
| density (near room temp) | 20.45 g/cm³ |
| phase at 20 °C | solid |
| melting point | 644 °C |
| boiling point | 3902 °C |
| appearance | see 09-optical-properties.md — colour #00d0ff in this library's palette |

Density is mass divided by volume: a cube of Neptunium measuring 1 cm on a side
weighs 20.45 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Neptunium is a solid at room temperature; heat it past 644 °C and it flows.
