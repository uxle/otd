# Fun facts about Neptunium

Neptunium was the first transuranium element ever made — element 93, beyond natural uranium.

More angles on the same element:
- atomic number 93 — in a periodic table sorted by Z, Np is entry #93
- one mole (237.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 20.45 g — sample 31 is exactly this cube
- its melting point 644 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
