# Physical properties of Gallium

| property | value |
|---|---|
| density (near room temp) | 5.91 g/cm³ |
| phase at 20 °C | solid |
| melting point | 29.8 °C |
| boiling point | 2400 °C |
| appearance | see 09-optical-properties.md — colour #c28f8f in this library's palette |

Density is mass divided by volume: a cube of Gallium measuring 1 cm on a side
weighs 5.91 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Gallium is a solid at room temperature; heat it past 29.8 °C and it flows.
