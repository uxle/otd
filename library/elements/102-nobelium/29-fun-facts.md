# Fun facts about Nobelium

Claims to have made nobelium were disputed for years — the Swedes, then Dubna, then Berkeley.

More angles on the same element:
- atomic number 102 — in a periodic table sorted by Z, No is entry #102
- one mole (259.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 9.9 g — sample 31 is exactly this cube
- its melting point 827 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
