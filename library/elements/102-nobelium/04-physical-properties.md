# Physical properties of Nobelium

| property | value |
|---|---|
| density (near room temp) | 9.9 g/cm³ |
| phase at 20 °C | solid |
| melting point | 827 °C |
| boiling point | 9999 °C |
| appearance | see 09-optical-properties.md — colour #00ffa0 in this library's palette |

Density is mass divided by volume: a cube of Nobelium measuring 1 cm on a side
weighs 9.9 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Nobelium is a solid at room temperature; heat it past 827 °C and it flows.
