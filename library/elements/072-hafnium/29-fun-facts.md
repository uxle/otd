# Fun facts about Hafnium

Hafnium eats neutrons — the opposite of zirconium — so reactors use both deliberately.

More angles on the same element:
- atomic number 72 — in a periodic table sorted by Z, Hf is entry #72
- one mole (178.49 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 13.31 g — sample 31 is exactly this cube
- its melting point 2233 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
