# Fun facts about Antimony

Ancient Egyptians ground antimony into kohl eyeliner 5,000 years ago.

More angles on the same element:
- atomic number 51 — in a periodic table sorted by Z, Sb is entry #51
- one mole (121.76 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 6.697 g — sample 31 is exactly this cube
- its melting point 630.6 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
