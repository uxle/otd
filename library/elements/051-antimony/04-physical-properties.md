# Physical properties of Antimony

| property | value |
|---|---|
| density (near room temp) | 6.697 g/cm³ |
| phase at 20 °C | solid |
| melting point | 630.6 °C |
| boiling point | 1587 °C |
| appearance | see 09-optical-properties.md — colour #9e63b5 in this library's palette |

Density is mass divided by volume: a cube of Antimony measuring 1 cm on a side
weighs 6.697 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Antimony is a solid at room temperature; heat it past 630.6 °C and it flows.
