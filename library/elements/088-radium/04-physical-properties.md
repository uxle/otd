# Physical properties of Radium

| property | value |
|---|---|
| density (near room temp) | 5.5 g/cm³ |
| phase at 20 °C | solid |
| melting point | 700 °C |
| boiling point | 1737 °C |
| appearance | see 09-optical-properties.md — colour #00ff9d in this library's palette |

Density is mass divided by volume: a cube of Radium measuring 1 cm on a side
weighs 5.5 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Radium is a solid at room temperature; heat it past 700 °C and it flows.
