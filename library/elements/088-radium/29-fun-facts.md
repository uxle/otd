# Fun facts about Radium

1920s watch dials glowed with radium — the painters licked their brushes and died young.

More angles on the same element:
- atomic number 88 — in a periodic table sorted by Z, Ra is entry #88
- one mole (226.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 5.5 g — sample 31 is exactly this cube
- its melting point 700 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
