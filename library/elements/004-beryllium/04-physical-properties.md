# Physical properties of Beryllium

| property | value |
|---|---|
| density (near room temp) | 1.85 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1287 °C |
| boiling point | 2469 °C |
| appearance | see 09-optical-properties.md — colour #c2ff00 in this library's palette |

Density is mass divided by volume: a cube of Beryllium measuring 1 cm on a side
weighs 1.85 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Beryllium is a solid at room temperature; heat it past 1287 °C and it flows.
