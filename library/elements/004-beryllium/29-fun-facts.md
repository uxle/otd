# Fun facts about Beryllium

Beryllium is transparent to X-rays — it was used to make the JWST mirrors.

More angles on the same element:
- atomic number 4 — in a periodic table sorted by Z, Be is entry #4
- one mole (9.0122 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 1.85 g — sample 31 is exactly this cube
- its melting point 1287 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
