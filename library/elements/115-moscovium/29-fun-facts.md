# Fun facts about Moscovium

Moscovium decayed away before its discoverers could even weigh a visible speck.

More angles on the same element:
- atomic number 115 — in a periodic table sorted by Z, Mc is entry #115
- one mole (290.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 13.5 g — sample 31 is exactly this cube
- its melting point 700 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
