# Physical properties of Europium

| property | value |
|---|---|
| density (near room temp) | 5.244 g/cm³ |
| phase at 20 °C | solid |
| melting point | 826 °C |
| boiling point | 1529 °C |
| appearance | see 09-optical-properties.md — colour #ff00ff in this library's palette |

Density is mass divided by volume: a cube of Europium measuring 1 cm on a side
weighs 5.244 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Europium is a solid at room temperature; heat it past 826 °C and it flows.
