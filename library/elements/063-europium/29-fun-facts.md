# Fun facts about Europium

Euro notes glow red under UV because of europium — an anti-counterfeit secret.

More angles on the same element:
- atomic number 63 — in a periodic table sorted by Z, Eu is entry #63
- one mole (151.96 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 5.244 g — sample 31 is exactly this cube
- its melting point 826 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
