# Fun facts about Gadolinium

Gadolinium is magnetic just below room temperature and warms when magnetised.

More angles on the same element:
- atomic number 64 — in a periodic table sorted by Z, Gd is entry #64
- one mole (157.25 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.9 g — sample 31 is exactly this cube
- its melting point 1312 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
