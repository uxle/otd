# Physical properties of Gadolinium

| property | value |
|---|---|
| density (near room temp) | 7.9 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1312 °C |
| boiling point | 3273 °C |
| appearance | see 09-optical-properties.md — colour #e6ffa6 in this library's palette |

Density is mass divided by volume: a cube of Gadolinium measuring 1 cm on a side
weighs 7.9 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Gadolinium is a solid at room temperature; heat it past 1312 °C and it flows.
