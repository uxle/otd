# Fun facts about Oganesson

Oganesson may be a reactive solid, not a noble gas — the periodic table's strangest ending.

More angles on the same element:
- atomic number 118 — in a periodic table sorted by Z, Og is entry #118
- one mole (294.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 5 g — sample 31 is exactly this cube
- its melting point 80 °C is reached in a match flame
- radioactive: handle with time, distance, shielding
