# Chemical behaviour of Oganesson

Oganesson reacts like a textbook noble gas:

- with air: none
- with water: none — these atoms refuse to react with water (or almost anything)
- with acids: none

Electronegativity: conventionally not quoted for this element.

The octet rule drives everything: atoms react to reach a full outer shell.
Noble gases already have one, which is why they almost never react.
Oganesson follows these rules so reliably that Mendeleev used family patterns
like this to predict elements before anyone had seen them.
