# Fun facts about Thallium

Thallium was the poisoner's poison — Agatha Christie built a novel around it.

More angles on the same element:
- atomic number 81 — in a periodic table sorted by Z, Tl is entry #81
- one mole (204.38 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 11.85 g — sample 31 is exactly this cube
- its melting point 304 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
