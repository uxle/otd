# Physical properties of Thallium

| property | value |
|---|---|
| density (near room temp) | 11.85 g/cm³ |
| phase at 20 °C | solid |
| melting point | 304 °C |
| boiling point | 1473 °C |
| appearance | see 09-optical-properties.md — colour #a6544d in this library's palette |

Density is mass divided by volume: a cube of Thallium measuring 1 cm on a side
weighs 11.85 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Thallium is a solid at room temperature; heat it past 304 °C and it flows.
