# Chemical behaviour of Mendelevium

Mendelevium reacts like a textbook actinide:

- with air: oxidise; fine uranium chips can catch fire spontaneously
- with water: reactive — uranium and plutonium corrode in water and must be stored dry
- with acids: dissolve in hydrochloric/nitric acid; uranium dissolves into a glowing green solution

Electronegativity: 1.3 on the Pauling scale — a measure of how strongly the atom pulls shared electrons.

The octet rule drives everything: atoms react to reach a full outer shell.
Metals lose electrons to become positive cations; nonmetals gain electrons to become anions; the exchange is a salt.
Mendelevium follows these rules so reliably that Mendeleev used family patterns
like this to predict elements before anyone had seen them.
