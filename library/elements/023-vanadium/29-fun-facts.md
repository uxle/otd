# Fun facts about Vanadium

Vanadium flow batteries can store grid-scale power in giant tanks of liquid.

More angles on the same element:
- atomic number 23 — in a periodic table sorted by Z, V is entry #23
- one mole (50.942 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 6.11 g — sample 31 is exactly this cube
- its melting point 1910 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
