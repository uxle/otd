# Physical properties of Vanadium

| property | value |
|---|---|
| density (near room temp) | 6.11 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1910 °C |
| boiling point | 3407 °C |
| appearance | see 09-optical-properties.md — colour #a6a6ab in this library's palette |

Density is mass divided by volume: a cube of Vanadium measuring 1 cm on a side
weighs 6.11 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Vanadium is a solid at room temperature; heat it past 1910 °C and it flows.
