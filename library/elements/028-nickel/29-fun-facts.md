# Fun facts about Nickel

Earth's core is mostly iron and nickel — a 2,400 km ball of metal.

More angles on the same element:
- atomic number 28 — in a periodic table sorted by Z, Ni is entry #28
- one mole (58.693 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 8.908 g — sample 31 is exactly this cube
- its melting point 1455 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
