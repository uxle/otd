# Fun facts about Erbium

The internet runs through erbium: it amplifies light inside every long fibre-optic cable.

More angles on the same element:
- atomic number 68 — in a periodic table sorted by Z, Er is entry #68
- one mole (167.26 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 9.066 g — sample 31 is exactly this cube
- its melting point 1529 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
