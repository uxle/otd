# Physical properties of Erbium

| property | value |
|---|---|
| density (near room temp) | 9.066 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1529 °C |
| boiling point | 2868 °C |
| appearance | see 09-optical-properties.md — colour #94d9ff in this library's palette |

Density is mass divided by volume: a cube of Erbium measuring 1 cm on a side
weighs 9.066 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Erbium is a solid at room temperature; heat it past 1529 °C and it flows.
