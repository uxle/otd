# Fun facts about Rutherfordium

Rutherfordium was fought over for 30 years before IUPAC settled the name in 1997.

More angles on the same element:
- atomic number 104 — in a periodic table sorted by Z, Rf is entry #104
- one mole (267.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 23.2 g — sample 31 is exactly this cube
- its melting point 2100 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
