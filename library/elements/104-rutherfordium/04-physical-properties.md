# Physical properties of Rutherfordium

| property | value |
|---|---|
| density (near room temp) | 23.2 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2100 °C |
| boiling point | 5500 °C |
| appearance | see 09-optical-properties.md — colour #50d0ff in this library's palette |

Density is mass divided by volume: a cube of Rutherfordium measuring 1 cm on a side
weighs 23.2 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Rutherfordium is a solid at room temperature; heat it past 2100 °C and it flows.
