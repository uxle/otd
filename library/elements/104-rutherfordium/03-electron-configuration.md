# Electron configuration of Rutherfordium (Rf)

Configuration: **[Rn] 5f14 6d2 7s2**

This notation records which sub-shells (s, p, d, f) hold the 104 electrons.
Read it as a build-up order: each sub-shell fills with at most 2 (s), 6 (p),
10 (d) or 14 (f) electrons, following the aufbau principle, the Pauli exclusion
principle, and Hund's rule.

- block: d — the last electron added enters an d sub-shell
- period 7: electrons are entering the n = 7 main shell
- group 4

The configuration explains the periodic law: elements in the same group share
the same valence configuration, so they behave alike. Rutherfordium's valence
electrons sit in the configuration shown above, which is why its reactions
follow the transition metal pattern: slow oxidation — rust for iron, patina for copper, nothing visible for gold.
