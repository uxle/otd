# Physical properties of Tin

| property | value |
|---|---|
| density (near room temp) | 7.31 g/cm³ |
| phase at 20 °C | solid |
| melting point | 231.9 °C |
| boiling point | 2602 °C |
| appearance | see 09-optical-properties.md — colour #668080 in this library's palette |

Density is mass divided by volume: a cube of Tin measuring 1 cm on a side
weighs 7.31 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Tin is a solid at room temperature; heat it past 231.9 °C and it flows.
