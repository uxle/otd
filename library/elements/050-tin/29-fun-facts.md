# Fun facts about Tin

When you bend a bar of tin, the crystals make a crackling 'tin cry'.

More angles on the same element:
- atomic number 50 — in a periodic table sorted by Z, Sn is entry #50
- one mole (118.71 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.31 g — sample 31 is exactly this cube
- its melting point 231.9 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
