# Physical properties of Helium

| property | value |
|---|---|
| density (near room temp) | 0.00018 g/cm³ |
| phase at 20 °C | gas |
| melting point | -272.2 °C |
| boiling point | -268.9 °C |
| appearance | see 09-optical-properties.md — colour #d9ffff in this library's palette |

Density is mass divided by volume: a cube of Helium measuring 1 cm on a side
weighs 0.00018 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

As a gas, Helium fills whatever volume it is given; the density above is for the gas at 0 °C and 1 atm.
