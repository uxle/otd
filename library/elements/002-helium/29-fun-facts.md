# Fun facts about Helium

Helium was found in the Sun's spectrum before it was found on Earth.

More angles on the same element:
- atomic number 2 — in a periodic table sorted by Z, He is entry #2
- one mole (4.0026 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.00018 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- stable: it has outlived the Earth so far and will outlive us
