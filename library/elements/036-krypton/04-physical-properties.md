# Physical properties of Krypton

| property | value |
|---|---|
| density (near room temp) | 0.0037 g/cm³ |
| phase at 20 °C | gas |
| melting point | -157.4 °C |
| boiling point | -153.2 °C |
| appearance | see 09-optical-properties.md — colour #5cb8d1 in this library's palette |

Density is mass divided by volume: a cube of Krypton measuring 1 cm on a side
weighs 0.0037 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

As a gas, Krypton fills whatever volume it is given; the density above is for the gas at 0 °C and 1 atm.
