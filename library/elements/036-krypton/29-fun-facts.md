# Fun facts about Krypton

For 23 years, the metre itself was defined by the orange light of krypton-86.

More angles on the same element:
- atomic number 36 — in a periodic table sorted by Z, Kr is entry #36
- one mole (83.798 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.0037 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- stable: it has outlived the Earth so far and will outlive us
