# Fun facts about Thorium

Thorium reactors could run on an abundant fuel that cannot easily be weaponised.

More angles on the same element:
- atomic number 90 — in a periodic table sorted by Z, Th is entry #90
- one mole (232.04 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 11.72 g — sample 31 is exactly this cube
- its melting point 1750 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
