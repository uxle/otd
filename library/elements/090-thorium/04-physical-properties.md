# Physical properties of Thorium

| property | value |
|---|---|
| density (near room temp) | 11.72 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1750 °C |
| boiling point | 4788 °C |
| appearance | see 09-optical-properties.md — colour #00a0ff in this library's palette |

Density is mass divided by volume: a cube of Thorium measuring 1 cm on a side
weighs 11.72 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Thorium is a solid at room temperature; heat it past 1750 °C and it flows.
