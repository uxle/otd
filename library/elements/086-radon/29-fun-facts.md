# Fun facts about Radon

Radon seeps from granite into basements — the invisible natural radiation in every home survey.

More angles on the same element:
- atomic number 86 — in a periodic table sorted by Z, Rn is entry #86
- one mole (222.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.0097 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- radioactive: handle with time, distance, shielding
