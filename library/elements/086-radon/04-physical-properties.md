# Physical properties of Radon

| property | value |
|---|---|
| density (near room temp) | 0.0097 g/cm³ |
| phase at 20 °C | gas |
| melting point | -71 °C |
| boiling point | -61.7 °C |
| appearance | see 09-optical-properties.md — colour #cc0080 in this library's palette |

Density is mass divided by volume: a cube of Radon measuring 1 cm on a side
weighs 0.0097 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

As a gas, Radon fills whatever volume it is given; the density above is for the gas at 0 °C and 1 atm.
