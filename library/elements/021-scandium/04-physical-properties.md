# Physical properties of Scandium

| property | value |
|---|---|
| density (near room temp) | 2.985 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1541 °C |
| boiling point | 2836 °C |
| appearance | see 09-optical-properties.md — colour #ffe08a in this library's palette |

Density is mass divided by volume: a cube of Scandium measuring 1 cm on a side
weighs 2.985 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Scandium is a solid at room temperature; heat it past 1541 °C and it flows.
