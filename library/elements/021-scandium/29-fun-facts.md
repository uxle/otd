# Fun facts about Scandium

Scandium is rare and expensive — one kilogram costs more than a used car.

More angles on the same element:
- atomic number 21 — in a periodic table sorted by Z, Sc is entry #21
- one mole (44.956 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 2.985 g — sample 31 is exactly this cube
- its melting point 1541 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
