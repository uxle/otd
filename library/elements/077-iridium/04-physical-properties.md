# Physical properties of Iridium

| property | value |
|---|---|
| density (near room temp) | 22.56 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2446 °C |
| boiling point | 4428 °C |
| appearance | see 09-optical-properties.md — colour #d4d4ff in this library's palette |

Density is mass divided by volume: a cube of Iridium measuring 1 cm on a side
weighs 22.56 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Iridium is a solid at room temperature; heat it past 2446 °C and it flows.
