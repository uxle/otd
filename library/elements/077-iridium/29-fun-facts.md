# Fun facts about Iridium

The dinosaur-killing asteroid left a thin iridium layer in rocks worldwide — the K-Pg line.

More angles on the same element:
- atomic number 77 — in a periodic table sorted by Z, Ir is entry #77
- one mole (192.22 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 22.56 g — sample 31 is exactly this cube
- its melting point 2446 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
