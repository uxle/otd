# Fun facts about Seaborgium

Seaborgium is the first element named after a living person.

More angles on the same element:
- atomic number 106 — in a periodic table sorted by Z, Sg is entry #106
- one mole (269.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 35 g — sample 31 is exactly this cube
- its melting point 2300 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
