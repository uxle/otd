# Fun facts about Darmstadtium

Darmstadtium was made by firing nickel at lead — one atom every few days.

More angles on the same element:
- atomic number 110 — in a periodic table sorted by Z, Ds is entry #110
- one mole (281.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 34.8 g — sample 31 is exactly this cube
- its melting point 2900 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
