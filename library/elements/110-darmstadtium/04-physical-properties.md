# Physical properties of Darmstadtium

| property | value |
|---|---|
| density (near room temp) | 34.8 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2900 °C |
| boiling point | 5500 °C |
| appearance | see 09-optical-properties.md — colour #ff30d0 in this library's palette |

Density is mass divided by volume: a cube of Darmstadtium measuring 1 cm on a side
weighs 34.8 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Darmstadtium is a solid at room temperature; heat it past 2900 °C and it flows.
