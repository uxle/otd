# Physical properties of Tennessine

| property | value |
|---|---|
| density (near room temp) | 7.2 g/cm³ |
| phase at 20 °C | solid |
| melting point | 700 °C |
| boiling point | 883 °C |
| appearance | see 09-optical-properties.md — colour #ffb040 in this library's palette |

Density is mass divided by volume: a cube of Tennessine measuring 1 cm on a side
weighs 7.2 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Tennessine is a solid at room temperature; heat it past 700 °C and it flows.
