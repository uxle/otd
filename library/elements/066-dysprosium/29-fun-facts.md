# Fun facts about Dysprosium

Without dysprosium, electric-car motors would lose their magnets when they warm up.

More angles on the same element:
- atomic number 66 — in a periodic table sorted by Z, Dy is entry #66
- one mole (162.5 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 8.54 g — sample 31 is exactly this cube
- its melting point 1407 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
