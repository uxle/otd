# Physical properties of Dysprosium

| property | value |
|---|---|
| density (near room temp) | 8.54 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1407 °C |
| boiling point | 2567 °C |
| appearance | see 09-optical-properties.md — colour #a6ffff in this library's palette |

Density is mass divided by volume: a cube of Dysprosium measuring 1 cm on a side
weighs 8.54 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Dysprosium is a solid at room temperature; heat it past 1407 °C and it flows.
