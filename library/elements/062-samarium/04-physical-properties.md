# Physical properties of Samarium

| property | value |
|---|---|
| density (near room temp) | 7.52 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1072 °C |
| boiling point | 1794 °C |
| appearance | see 09-optical-properties.md — colour #ff9b9b in this library's palette |

Density is mass divided by volume: a cube of Samarium measuring 1 cm on a side
weighs 7.52 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Samarium is a solid at room temperature; heat it past 1072 °C and it flows.
