# Fun facts about Samarium

Samarium-cobalt magnets keep working at 300 °C where neodymium ones give up.

More angles on the same element:
- atomic number 62 — in a periodic table sorted by Z, Sm is entry #62
- one mole (150.36 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.52 g — sample 31 is exactly this cube
- its melting point 1072 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
