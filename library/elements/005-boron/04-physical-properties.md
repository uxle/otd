# Physical properties of Boron

| property | value |
|---|---|
| density (near room temp) | 2.34 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2076 °C |
| boiling point | 3927 °C |
| appearance | see 09-optical-properties.md — colour #ffb5b5 in this library's palette |

Density is mass divided by volume: a cube of Boron measuring 1 cm on a side
weighs 2.34 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Boron is a solid at room temperature; heat it past 2076 °C and it flows.
