# Fun facts about Boron

Boron carbide is one of the hardest materials known — used in tank armour.

More angles on the same element:
- atomic number 5 — in a periodic table sorted by Z, B is entry #5
- one mole (10.81 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 2.34 g — sample 31 is exactly this cube
- its melting point 2076 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
