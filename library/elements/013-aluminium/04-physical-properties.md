# Physical properties of Aluminium

| property | value |
|---|---|
| density (near room temp) | 2.7 g/cm³ |
| phase at 20 °C | solid |
| melting point | 660.3 °C |
| boiling point | 2470 °C |
| appearance | see 09-optical-properties.md — colour #bfa6a6 in this library's palette |

Density is mass divided by volume: a cube of Aluminium measuring 1 cm on a side
weighs 2.7 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Aluminium is a solid at room temperature; heat it past 660.3 °C and it flows.
