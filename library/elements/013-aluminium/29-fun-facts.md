# Fun facts about Aluminium

A jet plane is roughly 80% aluminium by weight.

More angles on the same element:
- atomic number 13 — in a periodic table sorted by Z, Al is entry #13
- one mole (26.982 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 2.7 g — sample 31 is exactly this cube
- its melting point 660.3 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
