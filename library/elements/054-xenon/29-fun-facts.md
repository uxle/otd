# Fun facts about Xenon

Xenon ion thrusters are pushing spacecraft to asteroids right now.

More angles on the same element:
- atomic number 54 — in a periodic table sorted by Z, Xe is entry #54
- one mole (131.29 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.0059 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- stable: it has outlived the Earth so far and will outlive us
