# Physical properties of Xenon

| property | value |
|---|---|
| density (near room temp) | 0.0059 g/cm³ |
| phase at 20 °C | gas |
| melting point | -111.7 °C |
| boiling point | -108 °C |
| appearance | see 09-optical-properties.md — colour #429eb0 in this library's palette |

Density is mass divided by volume: a cube of Xenon measuring 1 cm on a side
weighs 0.0059 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

As a gas, Xenon fills whatever volume it is given; the density above is for the gas at 0 °C and 1 atm.
