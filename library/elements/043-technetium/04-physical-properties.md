# Physical properties of Technetium

| property | value |
|---|---|
| density (near room temp) | 11 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2157 °C |
| boiling point | 4265 °C |
| appearance | see 09-optical-properties.md — colour #3b9e9e in this library's palette |

Density is mass divided by volume: a cube of Technetium measuring 1 cm on a side
weighs 11 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Technetium is a solid at room temperature; heat it past 2157 °C and it flows.
