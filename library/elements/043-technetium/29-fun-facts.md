# Fun facts about Technetium

Technetium was the first element made artificially — every atom of it is radioactive.

More angles on the same element:
- atomic number 43 — in a periodic table sorted by Z, Tc is entry #43
- one mole (98.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 11 g — sample 31 is exactly this cube
- its melting point 2157 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
