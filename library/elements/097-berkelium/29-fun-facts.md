# Fun facts about Berkelium

Berkelium was made in a town that named a generation of elements: Berkeley Lab.

More angles on the same element:
- atomic number 97 — in a periodic table sorted by Z, Bk is entry #97
- one mole (247.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 14.78 g — sample 31 is exactly this cube
- its melting point 1050 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
