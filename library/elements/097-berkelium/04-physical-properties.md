# Physical properties of Berkelium

| property | value |
|---|---|
| density (near room temp) | 14.78 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1050 °C |
| boiling point | 2900 °C |
| appearance | see 09-optical-properties.md — colour #80ff40 in this library's palette |

Density is mass divided by volume: a cube of Berkelium measuring 1 cm on a side
weighs 14.78 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Berkelium is a solid at room temperature; heat it past 1050 °C and it flows.
