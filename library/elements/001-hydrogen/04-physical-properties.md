# Physical properties of Hydrogen

| property | value |
|---|---|
| density (near room temp) | 9e-05 g/cm³ |
| phase at 20 °C | gas |
| melting point | -259.2 °C |
| boiling point | -252.9 °C |
| appearance | see 09-optical-properties.md — colour #88ff88 in this library's palette |

Density is mass divided by volume: a cube of Hydrogen measuring 1 cm on a side
weighs 9e-05 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

As a gas, Hydrogen fills whatever volume it is given; the density above is for the gas at 0 °C and 1 atm.
