# Fun facts about Hydrogen

The most abundant element in the universe — about 75% of all normal matter.

More angles on the same element:
- atomic number 1 — in a periodic table sorted by Z, H is entry #1
- one mole (1.008 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 9e-05 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- stable: it has outlived the Earth so far and will outlive us
