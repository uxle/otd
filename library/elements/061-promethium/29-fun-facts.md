# Fun facts about Promethium

Promethium is the only radioactive lanthanide — it glows faintly in the dark.

More angles on the same element:
- atomic number 61 — in a periodic table sorted by Z, Pm is entry #61
- one mole (145.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.26 g — sample 31 is exactly this cube
- its melting point 1042 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
