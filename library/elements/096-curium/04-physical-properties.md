# Physical properties of Curium

| property | value |
|---|---|
| density (near room temp) | 13.51 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1345 °C |
| boiling point | 3110 °C |
| appearance | see 09-optical-properties.md — colour #80ffa0 in this library's palette |

Density is mass divided by volume: a cube of Curium measuring 1 cm on a side
weighs 13.51 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Curium is a solid at room temperature; heat it past 1345 °C and it flows.
