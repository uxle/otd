# Fun facts about Curium

Curium powers Mars rover instruments — it is named for the first radioactive researchers.

More angles on the same element:
- atomic number 96 — in a periodic table sorted by Z, Cm is entry #96
- one mole (247.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 13.51 g — sample 31 is exactly this cube
- its melting point 1345 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
