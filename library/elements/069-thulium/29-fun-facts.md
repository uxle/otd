# Fun facts about Thulium

Thulium X-ray machines are small enough to carry into the field — no tube needed.

More angles on the same element:
- atomic number 69 — in a periodic table sorted by Z, Tm is entry #69
- one mole (168.93 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 9.32 g — sample 31 is exactly this cube
- its melting point 1545 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
