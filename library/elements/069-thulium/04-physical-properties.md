# Physical properties of Thulium

| property | value |
|---|---|
| density (near room temp) | 9.32 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1545 °C |
| boiling point | 1950 °C |
| appearance | see 09-optical-properties.md — colour #8ccbe0 in this library's palette |

Density is mass divided by volume: a cube of Thulium measuring 1 cm on a side
weighs 9.32 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Thulium is a solid at room temperature; heat it past 1545 °C and it flows.
