# Fun facts about Lithium

Lithium is the lightest metal — it floats on oil, not just water.

More angles on the same element:
- atomic number 3 — in a periodic table sorted by Z, Li is entry #3
- one mole (6.94 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.534 g — sample 31 is exactly this cube
- its melting point 180.5 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
