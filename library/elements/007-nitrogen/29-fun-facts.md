# Fun facts about Nitrogen

About 78% of every breath you take is nitrogen gas.

More angles on the same element:
- atomic number 7 — in a periodic table sorted by Z, N is entry #7
- one mole (14.007 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.00125 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- stable: it has outlived the Earth so far and will outlive us
