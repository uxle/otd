# Fun facts about Rhenium

Rhenium is one of the rarest metals — a single jet engine holds kilograms of it.

More angles on the same element:
- atomic number 75 — in a periodic table sorted by Z, Re is entry #75
- one mole (186.21 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 21.02 g — sample 31 is exactly this cube
- its melting point 3186 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
