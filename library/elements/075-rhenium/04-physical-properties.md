# Physical properties of Rhenium

| property | value |
|---|---|
| density (near room temp) | 21.02 g/cm³ |
| phase at 20 °C | solid |
| melting point | 3186 °C |
| boiling point | 5596 °C |
| appearance | see 09-optical-properties.md — colour #d4a0a0 in this library's palette |

Density is mass divided by volume: a cube of Rhenium measuring 1 cm on a side
weighs 21.02 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Rhenium is a solid at room temperature; heat it past 3186 °C and it flows.
