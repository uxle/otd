# Quantum theory snapshot: Rhenium

Four quantum numbers describe every electron:
- **n** (principal) — the shell, n = 1, 2, 3 …
- **l** (azimuthal) — the sub-shell shape: s, p, d, f
- **mₗ** (magnetic) — the orientation in space
- **mₛ** (spin) — up or down; the Pauli exclusion principle forbids two electrons
  in the same atom sharing all four numbers

Rhenium's 75 electrons fill accordingly:
- n = 1: 2 electrons
- n = 2: 8 electrons
- n = 3: 18 electrons
- n = 4: 32 electrons

The configuration [Xe] 4f14 5d5 6s2 is the shorthand. Chemical periodicity — why the
table has the shape it has — is the direct consequence of these quantum rules:
shells fill to capacities 2, 8, 8, 18, 18, 32, and each new pattern begins a
new period. Mendeleev saw the pattern; quantum mechanics explained it.
