# Physical properties of Cobalt

| property | value |
|---|---|
| density (near room temp) | 8.9 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1495 °C |
| boiling point | 2927 °C |
| appearance | see 09-optical-properties.md — colour #f090a0 in this library's palette |

Density is mass divided by volume: a cube of Cobalt measuring 1 cm on a side
weighs 8.9 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Cobalt is a solid at room temperature; heat it past 1495 °C and it flows.
