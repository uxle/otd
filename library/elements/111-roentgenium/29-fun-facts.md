# Fun facts about Roentgenium

Roentgenium is predicted to be a noble metal — perhaps gold-like, but it decays in seconds.

More angles on the same element:
- atomic number 111 — in a periodic table sorted by Z, Rg is entry #111
- one mole (282.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 28.7 g — sample 31 is exactly this cube
- its melting point 2900 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
