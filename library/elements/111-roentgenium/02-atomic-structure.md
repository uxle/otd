# Atomic structure of Roentgenium

Roentgenium carries 111 protons. A neutral atom therefore holds exactly 111
electrons, arranged in 7 shells around the
nucleus. The most common isotope has mass number 282, so its nucleus holds
171 neutrons alongside the 111 protons.

## Electron shells
- shell n=1: 2 electrons
- shell n=2: 8 electrons
- shell n=3: 18 electrons
- shell n=4: 32 electrons
- shell n=5: 32 electrons
- shell n=6: 17 electrons
- shell n=7: 1 electron

## The nucleus
- protons: 111 (this is what makes it Roentgenium and nothing else)
- neutrons: about 171 (mass number 282)
- total nucleons: about 282

Electrons fill shells from the inside out: 2 in the first shell, 8 in the second,
18 in the third (with sub-shell bookkeeping the pattern continues 8, 18, 32 …).
The outermost electrons — the valence electrons — decide all of Rg's chemistry.
Roentgenium's chemical personality is that of a transition metal: slow oxidation — rust for iron, patina for copper, nothing visible for gold.
