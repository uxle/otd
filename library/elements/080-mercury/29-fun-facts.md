# Fun facts about Mercury

Mercury is the only metal liquid at room temperature — and it pours like silver syrup.

More angles on the same element:
- atomic number 80 — in a periodic table sorted by Z, Hg is entry #80
- one mole (200.59 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 13.534 g — sample 31 is exactly this cube
- its melting point -38.8 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
