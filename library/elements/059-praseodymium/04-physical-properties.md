# Physical properties of Praseodymium

| property | value |
|---|---|
| density (near room temp) | 6.773 g/cm³ |
| phase at 20 °C | solid |
| melting point | 935 °C |
| boiling point | 3520 °C |
| appearance | see 09-optical-properties.md — colour #dfffaf in this library's palette |

Density is mass divided by volume: a cube of Praseodymium measuring 1 cm on a side
weighs 6.773 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Praseodymium is a solid at room temperature; heat it past 935 °C and it flows.
