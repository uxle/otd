# Fun facts about Praseodymium

Praseodymium colours welders' goggles — it blocks the yellow glare of molten metal.

More angles on the same element:
- atomic number 59 — in a periodic table sorted by Z, Pr is entry #59
- one mole (140.91 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 6.773 g — sample 31 is exactly this cube
- its melting point 935 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
