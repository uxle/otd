# Physical properties of Plutonium

| property | value |
|---|---|
| density (near room temp) | 19.85 g/cm³ |
| phase at 20 °C | solid |
| melting point | 640 °C |
| boiling point | 3228 °C |
| appearance | see 09-optical-properties.md — colour #00e080 in this library's palette |

Density is mass divided by volume: a cube of Plutonium measuring 1 cm on a side
weighs 19.85 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Plutonium is a solid at room temperature; heat it past 640 °C and it flows.
