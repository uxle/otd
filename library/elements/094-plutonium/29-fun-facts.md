# Fun facts about Plutonium

The Voyager probes still phone home on plutonium heat — 20+ billion km away.

More angles on the same element:
- atomic number 94 — in a periodic table sorted by Z, Pu is entry #94
- one mole (244.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 19.85 g — sample 31 is exactly this cube
- its melting point 640 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
