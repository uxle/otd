# Fun facts about Sulfur

Sulfuric acid is among the most produced chemicals in the world — the 'king of chemicals'.

More angles on the same element:
- atomic number 16 — in a periodic table sorted by Z, S is entry #16
- one mole (32.06 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 2.07 g — sample 31 is exactly this cube
- its melting point 115.2 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
