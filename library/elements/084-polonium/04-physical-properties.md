# Physical properties of Polonium

| property | value |
|---|---|
| density (near room temp) | 9.2 g/cm³ |
| phase at 20 °C | solid |
| melting point | 254 °C |
| boiling point | 962 °C |
| appearance | see 09-optical-properties.md — colour #d8004d in this library's palette |

Density is mass divided by volume: a cube of Polonium measuring 1 cm on a side
weighs 9.2 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Polonium is a solid at room temperature; heat it past 254 °C and it flows.
