# Fun facts about Polonium

Polonium is so radioactive that a gram heats itself to 500 °C and glows blue.

More angles on the same element:
- atomic number 84 — in a periodic table sorted by Z, Po is entry #84
- one mole (209.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 9.2 g — sample 31 is exactly this cube
- its melting point 254 °C is reached in a match flame
- radioactive: handle with time, distance, shielding
