# Fun facts about Terbium

Terbium alloy 'Terfenol-D' changes shape in magnetic fields — it hums in sonar.

More angles on the same element:
- atomic number 65 — in a periodic table sorted by Z, Tb is entry #65
- one mole (158.93 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 8.23 g — sample 31 is exactly this cube
- its melting point 1356 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
