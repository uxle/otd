# Physical properties of Neodymium

| property | value |
|---|---|
| density (near room temp) | 7.01 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1024 °C |
| boiling point | 3074 °C |
| appearance | see 09-optical-properties.md — colour #8affde in this library's palette |

Density is mass divided by volume: a cube of Neodymium measuring 1 cm on a side
weighs 7.01 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Neodymium is a solid at room temperature; heat it past 1024 °C and it flows.
