# Fun facts about Neodymium

A neodymium magnet the size of a coin can lift 10 kg — and shatters if it snaps shut.

More angles on the same element:
- atomic number 60 — in a periodic table sorted by Z, Nd is entry #60
- one mole (144.24 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.01 g — sample 31 is exactly this cube
- its melting point 1024 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
