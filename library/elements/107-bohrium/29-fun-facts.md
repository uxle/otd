# Fun facts about Bohrium

Bohrium's chemistry was tested atom by atom — each experiment handled a handful of atoms.

More angles on the same element:
- atomic number 107 — in a periodic table sorted by Z, Bh is entry #107
- one mole (270.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 37.1 g — sample 31 is exactly this cube
- its melting point 2400 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
