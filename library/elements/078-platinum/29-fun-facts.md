# Fun facts about Platinum

All the platinum ever mined would fit in a 7-metre cube — scarcer than gold.

More angles on the same element:
- atomic number 78 — in a periodic table sorted by Z, Pt is entry #78
- one mole (195.08 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 21.45 g — sample 31 is exactly this cube
- its melting point 1768.3 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
