# Fun facts about Iron

Iron is the last element a star makes before it dies — fusion stops at iron.

More angles on the same element:
- atomic number 26 — in a periodic table sorted by Z, Fe is entry #26
- one mole (55.845 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.874 g — sample 31 is exactly this cube
- its melting point 1538 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
