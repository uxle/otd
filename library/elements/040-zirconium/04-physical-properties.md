# Physical properties of Zirconium

| property | value |
|---|---|
| density (near room temp) | 6.52 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1855 °C |
| boiling point | 4409 °C |
| appearance | see 09-optical-properties.md — colour #94e0e0 in this library's palette |

Density is mass divided by volume: a cube of Zirconium measuring 1 cm on a side
weighs 6.52 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Zirconium is a solid at room temperature; heat it past 1855 °C and it flows.
