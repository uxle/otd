# Fun facts about Zirconium

Zirconium barely absorbs neutrons — every nuclear submarine is clad in it.

More angles on the same element:
- atomic number 40 — in a periodic table sorted by Z, Zr is entry #40
- one mole (91.224 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 6.52 g — sample 31 is exactly this cube
- its melting point 1855 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
