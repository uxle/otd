# Physical properties of Caesium

| property | value |
|---|---|
| density (near room temp) | 1.879 g/cm³ |
| phase at 20 °C | solid |
| melting point | 28.4 °C |
| boiling point | 671 °C |
| appearance | see 09-optical-properties.md — colour #57178f in this library's palette |

Density is mass divided by volume: a cube of Caesium measuring 1 cm on a side
weighs 1.879 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Caesium is a solid at room temperature; heat it past 28.4 °C and it flows.
