# Fun facts about Caesium

The world's time is set by caesium — 9,192,631,770 oscillations per second.

More angles on the same element:
- atomic number 55 — in a periodic table sorted by Z, Cs is entry #55
- one mole (132.91 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 1.879 g — sample 31 is exactly this cube
- its melting point 28.4 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
