# Fun facts about Fermium

Fermium was also discovered in H-bomb debris and kept secret for three years.

More angles on the same element:
- atomic number 100 — in a periodic table sorted by Z, Fm is entry #100
- one mole (257.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 9.7 g — sample 31 is exactly this cube
- its melting point 1527 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
