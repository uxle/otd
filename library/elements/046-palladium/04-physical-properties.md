# Physical properties of Palladium

| property | value |
|---|---|
| density (near room temp) | 12.02 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1554.9 °C |
| boiling point | 2963 °C |
| appearance | see 09-optical-properties.md — colour #d0a0a0 in this library's palette |

Density is mass divided by volume: a cube of Palladium measuring 1 cm on a side
weighs 12.02 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Palladium is a solid at room temperature; heat it past 1554.9 °C and it flows.
