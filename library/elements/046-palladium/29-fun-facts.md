# Fun facts about Palladium

Palladium can soak up 900 times its own volume of hydrogen gas.

More angles on the same element:
- atomic number 46 — in a periodic table sorted by Z, Pd is entry #46
- one mole (106.42 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 12.02 g — sample 31 is exactly this cube
- its melting point 1554.9 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
