# Physical properties of Selenium

| property | value |
|---|---|
| density (near room temp) | 4.81 g/cm³ |
| phase at 20 °C | solid |
| melting point | 221 °C |
| boiling point | 685 °C |
| appearance | see 09-optical-properties.md — colour #ffa100 in this library's palette |

Density is mass divided by volume: a cube of Selenium measuring 1 cm on a side
weighs 4.81 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Selenium is a solid at room temperature; heat it past 221 °C and it flows.
