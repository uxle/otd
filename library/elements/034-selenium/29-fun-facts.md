# Fun facts about Selenium

Selenium conducts electricity better in light — the secret behind early photocopiers.

More angles on the same element:
- atomic number 34 — in a periodic table sorted by Z, Se is entry #34
- one mole (78.971 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 4.81 g — sample 31 is exactly this cube
- its melting point 221 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
