# Fun facts about Cadmium

Van Gogh's brilliant yellows were cadmium pigments — now they are being phased out.

More angles on the same element:
- atomic number 48 — in a periodic table sorted by Z, Cd is entry #48
- one mole (112.41 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 8.65 g — sample 31 is exactly this cube
- its melting point 321.1 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
