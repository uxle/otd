# Physical properties of Cadmium

| property | value |
|---|---|
| density (near room temp) | 8.65 g/cm³ |
| phase at 20 °C | solid |
| melting point | 321.1 °C |
| boiling point | 767 °C |
| appearance | see 09-optical-properties.md — colour #ffd98f in this library's palette |

Density is mass divided by volume: a cube of Cadmium measuring 1 cm on a side
weighs 8.65 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Cadmium is a solid at room temperature; heat it past 321.1 °C and it flows.
