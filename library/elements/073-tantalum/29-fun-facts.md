# Fun facts about Tantalum

Every smartphone holds a pinch of tantalum in its capacitors — tiny, vital, expensive.

More angles on the same element:
- atomic number 73 — in a periodic table sorted by Z, Ta is entry #73
- one mole (180.95 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 16.69 g — sample 31 is exactly this cube
- its melting point 3017 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
