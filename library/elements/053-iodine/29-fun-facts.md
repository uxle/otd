# Fun facts about Iodine

Iodine vapour is violet — its Greek name means exactly that.

More angles on the same element:
- atomic number 53 — in a periodic table sorted by Z, I is entry #53
- one mole (126.9 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 4.93 g — sample 31 is exactly this cube
- its melting point 113.7 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
