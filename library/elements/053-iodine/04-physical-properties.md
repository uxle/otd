# Physical properties of Iodine

| property | value |
|---|---|
| density (near room temp) | 4.93 g/cm³ |
| phase at 20 °C | solid |
| melting point | 113.7 °C |
| boiling point | 184.3 °C |
| appearance | see 09-optical-properties.md — colour #940094 in this library's palette |

Density is mass divided by volume: a cube of Iodine measuring 1 cm on a side
weighs 4.93 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Iodine is a solid at room temperature; heat it past 113.7 °C and it flows.
