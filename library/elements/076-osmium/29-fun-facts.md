# Fun facts about Osmium

Osmium is the densest natural element — a litre of it weighs 22.6 kg.

More angles on the same element:
- atomic number 76 — in a periodic table sorted by Z, Os is entry #76
- one mole (190.23 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 22.59 g — sample 31 is exactly this cube
- its melting point 3033 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
