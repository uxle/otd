# Physical properties of Osmium

| property | value |
|---|---|
| density (near room temp) | 22.59 g/cm³ |
| phase at 20 °C | solid |
| melting point | 3033 °C |
| boiling point | 5012 °C |
| appearance | see 09-optical-properties.md — colour #a0a0b0 in this library's palette |

Density is mass divided by volume: a cube of Osmium measuring 1 cm on a side
weighs 22.59 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Osmium is a solid at room temperature; heat it past 3033 °C and it flows.
