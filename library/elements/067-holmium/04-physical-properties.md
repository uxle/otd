# Physical properties of Holmium

| property | value |
|---|---|
| density (near room temp) | 8.79 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1461 °C |
| boiling point | 2720 °C |
| appearance | see 09-optical-properties.md — colour #a6d9ff in this library's palette |

Density is mass divided by volume: a cube of Holmium measuring 1 cm on a side
weighs 8.79 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Holmium is a solid at room temperature; heat it past 1461 °C and it flows.
