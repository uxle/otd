# Fun facts about Holmium

Holmium has the strongest magnetic moment of any element — magnetic focusing uses it.

More angles on the same element:
- atomic number 67 — in a periodic table sorted by Z, Ho is entry #67
- one mole (164.93 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 8.79 g — sample 31 is exactly this cube
- its melting point 1461 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
