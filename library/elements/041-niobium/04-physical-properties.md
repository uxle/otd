# Physical properties of Niobium

| property | value |
|---|---|
| density (near room temp) | 8.57 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2477 °C |
| boiling point | 4744 °C |
| appearance | see 09-optical-properties.md — colour #73c2c9 in this library's palette |

Density is mass divided by volume: a cube of Niobium measuring 1 cm on a side
weighs 8.57 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Niobium is a solid at room temperature; heat it past 2477 °C and it flows.
