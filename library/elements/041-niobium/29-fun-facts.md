# Fun facts about Niobium

The LHC accelerates protons using 1,200 tonnes of niobium-titanium superconductor.

More angles on the same element:
- atomic number 41 — in a periodic table sorted by Z, Nb is entry #41
- one mole (92.906 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 8.57 g — sample 31 is exactly this cube
- its melting point 2477 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
