# Physical properties of Potassium

| property | value |
|---|---|
| density (near room temp) | 0.862 g/cm³ |
| phase at 20 °C | solid |
| melting point | 63.5 °C |
| boiling point | 759 °C |
| appearance | see 09-optical-properties.md — colour #8f40d4 in this library's palette |

Density is mass divided by volume: a cube of Potassium measuring 1 cm on a side
weighs 0.862 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Potassium is a solid at room temperature; heat it past 63.5 °C and it flows.
