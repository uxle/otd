# Fun facts about Potassium

Your nerves fire using potassium ions — bananas are radioactive for this reason.

More angles on the same element:
- atomic number 19 — in a periodic table sorted by Z, K is entry #19
- one mole (39.098 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.862 g — sample 31 is exactly this cube
- its melting point 63.5 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
