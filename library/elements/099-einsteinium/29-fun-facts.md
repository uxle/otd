# Fun facts about Einsteinium

Einsteinium was found in the fallout of the first hydrogen-bomb test — born in a fireball.

More angles on the same element:
- atomic number 99 — in a periodic table sorted by Z, Es is entry #99
- one mole (252.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 8.84 g — sample 31 is exactly this cube
- its melting point 860 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
