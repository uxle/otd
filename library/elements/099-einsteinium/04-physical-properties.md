# Physical properties of Einsteinium

| property | value |
|---|---|
| density (near room temp) | 8.84 g/cm³ |
| phase at 20 °C | solid |
| melting point | 860 °C |
| boiling point | 996 °C |
| appearance | see 09-optical-properties.md — colour #40ff10 in this library's palette |

Density is mass divided by volume: a cube of Einsteinium measuring 1 cm on a side
weighs 8.84 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Einsteinium is a solid at room temperature; heat it past 860 °C and it flows.
