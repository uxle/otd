# Physical properties of Flerovium

| property | value |
|---|---|
| density (near room temp) | 14 g/cm³ |
| phase at 20 °C | solid |
| melting point | 700 °C |
| boiling point | 1500 °C |
| appearance | see 09-optical-properties.md — colour #ff5050 in this library's palette |

Density is mass divided by volume: a cube of Flerovium measuring 1 cm on a side
weighs 14 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Flerovium is a solid at room temperature; heat it past 700 °C and it flows.
