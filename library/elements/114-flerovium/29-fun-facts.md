# Fun facts about Flerovium

Flerovium sits at the 'island of stability', where superheavy atoms live a bit longer.

More angles on the same element:
- atomic number 114 — in a periodic table sorted by Z, Fl is entry #114
- one mole (289.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 14 g — sample 31 is exactly this cube
- its melting point 700 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
