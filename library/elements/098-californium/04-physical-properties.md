# Physical properties of Californium

| property | value |
|---|---|
| density (near room temp) | 15.1 g/cm³ |
| phase at 20 °C | solid |
| melting point | 900 °C |
| boiling point | 1470 °C |
| appearance | see 09-optical-properties.md — colour #60ff30 in this library's palette |

Density is mass divided by volume: a cube of Californium measuring 1 cm on a side
weighs 15.1 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Californium is a solid at room temperature; heat it past 900 °C and it flows.
