# Fun facts about Californium

One microgram of californium fires 170 million neutrons per minute — a start button for reactors.

More angles on the same element:
- atomic number 98 — in a periodic table sorted by Z, Cf is entry #98
- one mole (251.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 15.1 g — sample 31 is exactly this cube
- its melting point 900 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
