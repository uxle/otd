# Physical properties of Ytterbium

| property | value |
|---|---|
| density (near room temp) | 6.9 g/cm³ |
| phase at 20 °C | solid |
| melting point | 824 °C |
| boiling point | 1196 °C |
| appearance | see 09-optical-properties.md — colour #bfbfe8 in this library's palette |

Density is mass divided by volume: a cube of Ytterbium measuring 1 cm on a side
weighs 6.9 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Ytterbium is a solid at room temperature; heat it past 824 °C and it flows.
