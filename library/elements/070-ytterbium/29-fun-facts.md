# Fun facts about Ytterbium

Ytterbium clocks are so precise they sense time dilation when lifted 30 cm.

More angles on the same element:
- atomic number 70 — in a periodic table sorted by Z, Yb is entry #70
- one mole (173.05 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 6.9 g — sample 31 is exactly this cube
- its melting point 824 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
