# Physical properties of Phosphorus

| property | value |
|---|---|
| density (near room temp) | 1.823 g/cm³ |
| phase at 20 °C | solid |
| melting point | 44.2 °C |
| boiling point | 280.5 °C |
| appearance | see 09-optical-properties.md — colour #ff8000 in this library's palette |

Density is mass divided by volume: a cube of Phosphorus measuring 1 cm on a side
weighs 1.823 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Phosphorus is a solid at room temperature; heat it past 44.2 °C and it flows.
