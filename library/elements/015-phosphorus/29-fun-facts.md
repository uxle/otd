# Fun facts about Phosphorus

Phosphorus was discovered in boiled urine — the first element with a known discoverer.

More angles on the same element:
- atomic number 15 — in a periodic table sorted by Z, P is entry #15
- one mole (30.974 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 1.823 g — sample 31 is exactly this cube
- its melting point 44.2 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
