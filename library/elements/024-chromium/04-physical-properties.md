# Physical properties of Chromium

| property | value |
|---|---|
| density (near room temp) | 7.19 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1907 °C |
| boiling point | 2671 °C |
| appearance | see 09-optical-properties.md — colour #8a99c7 in this library's palette |

Density is mass divided by volume: a cube of Chromium measuring 1 cm on a side
weighs 7.19 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Chromium is a solid at room temperature; heat it past 1907 °C and it flows.
