# Fun facts about Chromium

Ruby red and emerald green both come from traces of the same element: chromium.

More angles on the same element:
- atomic number 24 — in a periodic table sorted by Z, Cr is entry #24
- one mole (51.996 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.19 g — sample 31 is exactly this cube
- its melting point 1907 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
