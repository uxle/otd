# Physical properties of Nihonium

| property | value |
|---|---|
| density (near room temp) | 16 g/cm³ |
| phase at 20 °C | solid |
| melting point | 700 °C |
| boiling point | 1430 °C |
| appearance | see 09-optical-properties.md — colour #ff3060 in this library's palette |

Density is mass divided by volume: a cube of Nihonium measuring 1 cm on a side
weighs 16 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Nihonium is a solid at room temperature; heat it past 700 °C and it flows.
