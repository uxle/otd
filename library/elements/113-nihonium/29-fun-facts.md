# Fun facts about Nihonium

Nihonium was the first element discovered in Asia — named for Japan itself.

More angles on the same element:
- atomic number 113 — in a periodic table sorted by Z, Nh is entry #113
- one mole (286.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 16 g — sample 31 is exactly this cube
- its melting point 700 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
