# Physical properties of Barium

| property | value |
|---|---|
| density (near room temp) | 3.51 g/cm³ |
| phase at 20 °C | solid |
| melting point | 727 °C |
| boiling point | 1897 °C |
| appearance | see 09-optical-properties.md — colour #00c900 in this library's palette |

Density is mass divided by volume: a cube of Barium measuring 1 cm on a side
weighs 3.51 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Barium is a solid at room temperature; heat it past 727 °C and it flows.
