# Fun facts about Barium

Barium meals make the gut visible on X-rays — inert sulfate only.

More angles on the same element:
- atomic number 56 — in a periodic table sorted by Z, Ba is entry #56
- one mole (137.33 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 3.51 g — sample 31 is exactly this cube
- its melting point 727 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
