# Fun facts about Molybdenum

Molybdenum keeps its strength at 1,500 °C — armour-piercing rounds use it.

More angles on the same element:
- atomic number 42 — in a periodic table sorted by Z, Mo is entry #42
- one mole (95.95 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 10.28 g — sample 31 is exactly this cube
- its melting point 2623 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
