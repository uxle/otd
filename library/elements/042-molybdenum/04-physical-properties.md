# Physical properties of Molybdenum

| property | value |
|---|---|
| density (near room temp) | 10.28 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2623 °C |
| boiling point | 4639 °C |
| appearance | see 09-optical-properties.md — colour #54b5b5 in this library's palette |

Density is mass divided by volume: a cube of Molybdenum measuring 1 cm on a side
weighs 10.28 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Molybdenum is a solid at room temperature; heat it past 2623 °C and it flows.
