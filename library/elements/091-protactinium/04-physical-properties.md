# Physical properties of Protactinium

| property | value |
|---|---|
| density (near room temp) | 15.37 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1572 °C |
| boiling point | 4000 °C |
| appearance | see 09-optical-properties.md — colour #00bfff in this library's palette |

Density is mass divided by volume: a cube of Protactinium measuring 1 cm on a side
weighs 15.37 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Protactinium is a solid at room temperature; heat it past 1572 °C and it flows.
