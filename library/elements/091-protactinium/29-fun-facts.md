# Fun facts about Protactinium

Protactinium is one of the rarest natural elements — UK once refined 125 g for dating studies.

More angles on the same element:
- atomic number 91 — in a periodic table sorted by Z, Pa is entry #91
- one mole (231.04 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 15.37 g — sample 31 is exactly this cube
- its melting point 1572 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
