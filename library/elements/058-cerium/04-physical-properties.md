# Physical properties of Cerium

| property | value |
|---|---|
| density (near room temp) | 6.77 g/cm³ |
| phase at 20 °C | solid |
| melting point | 795 °C |
| boiling point | 3443 °C |
| appearance | see 09-optical-properties.md — colour #ffd1d1 in this library's palette |

Density is mass divided by volume: a cube of Cerium measuring 1 cm on a side
weighs 6.77 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Cerium is a solid at room temperature; heat it past 795 °C and it flows.
