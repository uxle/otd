# Fun facts about Cerium

Cerium sparks are the flash in every lighter — strike, spark, flame.

More angles on the same element:
- atomic number 58 — in a periodic table sorted by Z, Ce is entry #58
- one mole (140.12 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 6.77 g — sample 31 is exactly this cube
- its melting point 795 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
