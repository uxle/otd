# Physical properties of Meitnerium

| property | value |
|---|---|
| density (near room temp) | 37.4 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2800 °C |
| boiling point | 5500 °C |
| appearance | see 09-optical-properties.md — colour #d040ff in this library's palette |

Density is mass divided by volume: a cube of Meitnerium measuring 1 cm on a side
weighs 37.4 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Meitnerium is a solid at room temperature; heat it past 2800 °C and it flows.
