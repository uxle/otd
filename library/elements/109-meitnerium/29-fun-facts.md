# Fun facts about Meitnerium

Meitnerium honours Lise Meitner, co-discoverer of nuclear fission, denied her Nobel.

More angles on the same element:
- atomic number 109 — in a periodic table sorted by Z, Mt is entry #109
- one mole (278.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 37.4 g — sample 31 is exactly this cube
- its melting point 2800 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
