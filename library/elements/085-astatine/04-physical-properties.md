# Physical properties of Astatine

| property | value |
|---|---|
| density (near room temp) | 7 g/cm³ |
| phase at 20 °C | solid |
| melting point | 302 °C |
| boiling point | 337 °C |
| appearance | see 09-optical-properties.md — colour #cc0066 in this library's palette |

Density is mass divided by volume: a cube of Astatine measuring 1 cm on a side
weighs 7 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Astatine is a solid at room temperature; heat it past 302 °C and it flows.
