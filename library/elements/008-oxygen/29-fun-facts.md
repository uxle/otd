# Fun facts about Oxygen

Liquid oxygen is pale blue and magnetic — it sticks to a magnet.

More angles on the same element:
- atomic number 8 — in a periodic table sorted by Z, O is entry #8
- one mole (15.999 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.00143 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- stable: it has outlived the Earth so far and will outlive us
