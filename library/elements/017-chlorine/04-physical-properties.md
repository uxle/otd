# Physical properties of Chlorine

| property | value |
|---|---|
| density (near room temp) | 0.0032 g/cm³ |
| phase at 20 °C | gas |
| melting point | -101.5 °C |
| boiling point | -34 °C |
| appearance | see 09-optical-properties.md — colour #1ff01f in this library's palette |

Density is mass divided by volume: a cube of Chlorine measuring 1 cm on a side
weighs 0.0032 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

As a gas, Chlorine fills whatever volume it is given; the density above is for the gas at 0 °C and 1 atm.
