# Fun facts about Chlorine

Chlorine gas is green-yellow and was used as a chemical weapon in WWI.

More angles on the same element:
- atomic number 17 — in a periodic table sorted by Z, Cl is entry #17
- one mole (35.45 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.0032 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- stable: it has outlived the Earth so far and will outlive us
