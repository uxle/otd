# Fun facts about Actinium

Actinium glows pale blue in the dark — radioactivity made visible.

More angles on the same element:
- atomic number 89 — in a periodic table sorted by Z, Ac is entry #89
- one mole (227.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 10.07 g — sample 31 is exactly this cube
- its melting point 1050 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
