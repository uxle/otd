# Physical properties of Actinium

| property | value |
|---|---|
| density (near room temp) | 10.07 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1050 °C |
| boiling point | 3200 °C |
| appearance | see 09-optical-properties.md — colour #007fff in this library's palette |

Density is mass divided by volume: a cube of Actinium measuring 1 cm on a side
weighs 10.07 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Actinium is a solid at room temperature; heat it past 1050 °C and it flows.
