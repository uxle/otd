# Electron configuration of Tellurium (Te)

Configuration: **[Kr] 4d10 5s2 5p4**

This notation records which sub-shells (s, p, d, f) hold the 52 electrons.
Read it as a build-up order: each sub-shell fills with at most 2 (s), 6 (p),
10 (d) or 14 (f) electrons, following the aufbau principle, the Pauli exclusion
principle, and Hund's rule.

- block: p — the last electron added enters an p sub-shell
- period 5: electrons are entering the n = 5 main shell
- group 16 — chalcogens

The configuration explains the periodic law: elements in the same group share
the same valence configuration, so they behave alike. Tellurium's valence
electrons sit in the configuration shown above, which is why its reactions
follow the metalloid pattern: slow surface oxidation.
