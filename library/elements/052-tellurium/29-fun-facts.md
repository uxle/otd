# Fun facts about Tellurium

Tellurium is rarer than gold in Earth's crust, yet it costs far less.

More angles on the same element:
- atomic number 52 — in a periodic table sorted by Z, Te is entry #52
- one mole (127.6 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 6.24 g — sample 31 is exactly this cube
- its melting point 449.5 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
