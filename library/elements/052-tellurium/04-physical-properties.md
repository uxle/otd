# Physical properties of Tellurium

| property | value |
|---|---|
| density (near room temp) | 6.24 g/cm³ |
| phase at 20 °C | solid |
| melting point | 449.5 °C |
| boiling point | 988 °C |
| appearance | see 09-optical-properties.md — colour #d47a00 in this library's palette |

Density is mass divided by volume: a cube of Tellurium measuring 1 cm on a side
weighs 6.24 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Tellurium is a solid at room temperature; heat it past 449.5 °C and it flows.
