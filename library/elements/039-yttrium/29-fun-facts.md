# Fun facts about Yttrium

Four elements come from one tiny Swedish village: yttrium, ytterbium, terbium, erbium.

More angles on the same element:
- atomic number 39 — in a periodic table sorted by Z, Y is entry #39
- one mole (88.906 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 4.472 g — sample 31 is exactly this cube
- its melting point 1526 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
