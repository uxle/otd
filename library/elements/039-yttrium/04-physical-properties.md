# Physical properties of Yttrium

| property | value |
|---|---|
| density (near room temp) | 4.472 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1526 °C |
| boiling point | 3336 °C |
| appearance | see 09-optical-properties.md — colour #94ffff in this library's palette |

Density is mass divided by volume: a cube of Yttrium measuring 1 cm on a side
weighs 4.472 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Yttrium is a solid at room temperature; heat it past 1526 °C and it flows.
