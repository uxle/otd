# Fun facts about Francium

Francium is so rare and short-lived that nobody has ever seen a visible piece of it.

More angles on the same element:
- atomic number 87 — in a periodic table sorted by Z, Fr is entry #87
- one mole (223.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 1.87 g — sample 31 is exactly this cube
- its melting point 27 °C is reached in a match flame
- radioactive: handle with time, distance, shielding
