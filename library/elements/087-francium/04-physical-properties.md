# Physical properties of Francium

| property | value |
|---|---|
| density (near room temp) | 1.87 g/cm³ |
| phase at 20 °C | solid |
| melting point | 27 °C |
| boiling point | 677 °C |
| appearance | see 09-optical-properties.md — colour #ff00ff in this library's palette |

Density is mass divided by volume: a cube of Francium measuring 1 cm on a side
weighs 1.87 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Francium is a solid at room temperature; heat it past 27 °C and it flows.
