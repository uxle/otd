# Fun facts about Bromine

Bromine is one of only two elements that are liquid at room temperature.

More angles on the same element:
- atomic number 35 — in a periodic table sorted by Z, Br is entry #35
- one mole (79.904 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 3.12 g — sample 31 is exactly this cube
- its melting point -7.2 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
