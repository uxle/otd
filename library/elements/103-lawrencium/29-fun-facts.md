# Fun facts about Lawrencium

Lawrencium closes the actinide row — element 103, named for the cyclotron's inventor.

More angles on the same element:
- atomic number 103 — in a periodic table sorted by Z, Lr is entry #103
- one mole (266.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 15.6 g — sample 31 is exactly this cube
- its melting point 1627 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
