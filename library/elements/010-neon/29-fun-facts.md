# Fun facts about Neon

Neon glows the classic red-orange; every other noble-gas colour is an impostor mix.

More angles on the same element:
- atomic number 10 — in a periodic table sorted by Z, Ne is entry #10
- one mole (20.18 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 0.0009 g — sample 31 is exactly this cube
- it never sits still long enough to melt visibly — it is a gas at any normal temperature
- stable: it has outlived the Earth so far and will outlive us
