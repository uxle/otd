# Physical properties of Calcium

| property | value |
|---|---|
| density (near room temp) | 1.55 g/cm³ |
| phase at 20 °C | solid |
| melting point | 842 °C |
| boiling point | 1484 °C |
| appearance | see 09-optical-properties.md — colour #3dff00 in this library's palette |

Density is mass divided by volume: a cube of Calcium measuring 1 cm on a side
weighs 1.55 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Calcium is a solid at room temperature; heat it past 842 °C and it flows.
