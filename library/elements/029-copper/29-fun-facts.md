# Fun facts about Copper

Copper is naturally antimicrobial — door handles made of it kill germs on contact.

More angles on the same element:
- atomic number 29 — in a periodic table sorted by Z, Cu is entry #29
- one mole (63.546 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 8.96 g — sample 31 is exactly this cube
- its melting point 1084.6 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
