# Physical properties of Copper

| property | value |
|---|---|
| density (near room temp) | 8.96 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1084.6 °C |
| boiling point | 2562 °C |
| appearance | see 09-optical-properties.md — colour #c88033 in this library's palette |

Density is mass divided by volume: a cube of Copper measuring 1 cm on a side
weighs 8.96 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Copper is a solid at room temperature; heat it past 1084.6 °C and it flows.
