# Fun facts about Indium

Every smartphone touchscreen is coated with invisible indium tin oxide.

More angles on the same element:
- atomic number 49 — in a periodic table sorted by Z, In is entry #49
- one mole (114.82 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 7.31 g — sample 31 is exactly this cube
- its melting point 156.6 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
