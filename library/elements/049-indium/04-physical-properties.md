# Physical properties of Indium

| property | value |
|---|---|
| density (near room temp) | 7.31 g/cm³ |
| phase at 20 °C | solid |
| melting point | 156.6 °C |
| boiling point | 2072 °C |
| appearance | see 09-optical-properties.md — colour #a67573 in this library's palette |

Density is mass divided by volume: a cube of Indium measuring 1 cm on a side
weighs 7.31 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Indium is a solid at room temperature; heat it past 156.6 °C and it flows.
