# Physical properties of Argon

| property | value |
|---|---|
| density (near room temp) | 0.0018 g/cm³ |
| phase at 20 °C | gas |
| melting point | -189.3 °C |
| boiling point | -185.8 °C |
| appearance | see 09-optical-properties.md — colour #80d1e3 in this library's palette |

Density is mass divided by volume: a cube of Argon measuring 1 cm on a side
weighs 0.0018 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

As a gas, Argon fills whatever volume it is given; the density above is for the gas at 0 °C and 1 atm.
