# Physical properties of Hassium

| property | value |
|---|---|
| density (near room temp) | 40.7 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2500 °C |
| boiling point | 5500 °C |
| appearance | see 09-optical-properties.md — colour #c060ff in this library's palette |

Density is mass divided by volume: a cube of Hassium measuring 1 cm on a side
weighs 40.7 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Hassium is a solid at room temperature; heat it past 2500 °C and it flows.
