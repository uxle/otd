# Fun facts about Hassium

Hassium's state at room temperature is guessed — only a few hundred atoms ever existed.

More angles on the same element:
- atomic number 108 — in a periodic table sorted by Z, Hs is entry #108
- one mole (269.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 40.7 g — sample 31 is exactly this cube
- its melting point 2500 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
