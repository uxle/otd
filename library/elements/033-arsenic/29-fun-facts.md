# Fun facts about Arsenic

Arsenic was the poison of kings — tasteless, colourless, and undetectable for centuries.

More angles on the same element:
- atomic number 33 — in a periodic table sorted by Z, As is entry #33
- one mole (74.922 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 5.727 g — sample 31 is exactly this cube
- its melting point 817 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
