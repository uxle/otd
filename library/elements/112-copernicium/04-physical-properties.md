# Physical properties of Copernicium

| property | value |
|---|---|
| density (near room temp) | 23.7 g/cm³ |
| phase at 20 °C | solid |
| melting point | 2850 °C |
| boiling point | 3400 °C |
| appearance | see 09-optical-properties.md — colour #ff1050 in this library's palette |

Density is mass divided by volume: a cube of Copernicium measuring 1 cm on a side
weighs 23.7 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Copernicium is a solid at room temperature; heat it past 2850 °C and it flows.
