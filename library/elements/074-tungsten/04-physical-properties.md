# Physical properties of Tungsten

| property | value |
|---|---|
| density (near room temp) | 19.25 g/cm³ |
| phase at 20 °C | solid |
| melting point | 3422 °C |
| boiling point | 5555 °C |
| appearance | see 09-optical-properties.md — colour #2194d6 in this library's palette |

Density is mass divided by volume: a cube of Tungsten measuring 1 cm on a side
weighs 19.25 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Tungsten is a solid at room temperature; heat it past 3422 °C and it flows.
