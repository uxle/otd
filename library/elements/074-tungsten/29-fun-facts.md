# Fun facts about Tungsten

Tungsten has the highest melting point of any metal — 3,422 °C, white-hot and still solid.

More angles on the same element:
- atomic number 74 — in a periodic table sorted by Z, W is entry #74
- one mole (183.84 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 19.25 g — sample 31 is exactly this cube
- its melting point 3422 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
