# Physical properties of Bismuth

| property | value |
|---|---|
| density (near room temp) | 9.78 g/cm³ |
| phase at 20 °C | solid |
| melting point | 271.4 °C |
| boiling point | 1564 °C |
| appearance | see 09-optical-properties.md — colour #9c7ac7 in this library's palette |

Density is mass divided by volume: a cube of Bismuth measuring 1 cm on a side
weighs 9.78 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Bismuth is a solid at room temperature; heat it past 271.4 °C and it flows.
