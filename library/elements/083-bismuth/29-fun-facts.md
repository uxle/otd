# Fun facts about Bismuth

Bismuth grows rainbow staircase crystals in your kitchen — melt, cool, and watch.

More angles on the same element:
- atomic number 83 — in a periodic table sorted by Z, Bi is entry #83
- one mole (208.98 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 9.78 g — sample 31 is exactly this cube
- its melting point 271.4 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
