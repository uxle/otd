# Fun facts about Livermorium

Livermorium honours the lab whose town also gave its name to element 115's discoverers.

More angles on the same element:
- atomic number 116 — in a periodic table sorted by Z, Lv is entry #116
- one mole (293.0 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 12.9 g — sample 31 is exactly this cube
- its melting point 700 °C is reached in a furnace
- radioactive: handle with time, distance, shielding
