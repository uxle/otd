# Physical properties of Livermorium

| property | value |
|---|---|
| density (near room temp) | 12.9 g/cm³ |
| phase at 20 °C | solid |
| melting point | 700 °C |
| boiling point | 1100 °C |
| appearance | see 09-optical-properties.md — colour #ff9040 in this library's palette |

Density is mass divided by volume: a cube of Livermorium measuring 1 cm on a side
weighs 12.9 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Livermorium is a solid at room temperature; heat it past 700 °C and it flows.
