# Physical properties of Rubidium

| property | value |
|---|---|
| density (near room temp) | 1.532 g/cm³ |
| phase at 20 °C | solid |
| melting point | 39.3 °C |
| boiling point | 688 °C |
| appearance | see 09-optical-properties.md — colour #702eb0 in this library's palette |

Density is mass divided by volume: a cube of Rubidium measuring 1 cm on a side
weighs 1.532 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Rubidium is a solid at room temperature; heat it past 39.3 °C and it flows.
