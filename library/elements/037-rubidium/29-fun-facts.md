# Fun facts about Rubidium

Rubidium atomic clocks lose one second every 100 million years.

More angles on the same element:
- atomic number 37 — in a periodic table sorted by Z, Rb is entry #37
- one mole (85.468 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 1.532 g — sample 31 is exactly this cube
- its melting point 39.3 °C is reached in a match flame
- stable: it has outlived the Earth so far and will outlive us
