# Physical properties of Uranium

| property | value |
|---|---|
| density (near room temp) | 19.1 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1135 °C |
| boiling point | 4131 °C |
| appearance | see 09-optical-properties.md — colour #00c8c8 in this library's palette |

Density is mass divided by volume: a cube of Uranium measuring 1 cm on a side
weighs 19.1 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Uranium is a solid at room temperature; heat it past 1135 °C and it flows.
