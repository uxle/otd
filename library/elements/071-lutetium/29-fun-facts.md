# Fun facts about Lutetium

Lutetium crystals in PET scanners catch the flash of cancer-tracing positrons.

More angles on the same element:
- atomic number 71 — in a periodic table sorted by Z, Lu is entry #71
- one mole (174.97 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 9.841 g — sample 31 is exactly this cube
- its melting point 1652 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
