# Physical properties of Lutetium

| property | value |
|---|---|
| density (near room temp) | 9.841 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1652 °C |
| boiling point | 3402 °C |
| appearance | see 09-optical-properties.md — colour #a6a6ff in this library's palette |

Density is mass divided by volume: a cube of Lutetium measuring 1 cm on a side
weighs 9.841 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Lutetium is a solid at room temperature; heat it past 1652 °C and it flows.
