# Fun facts about Strontium

Strontium gives fireworks their brilliant crimson red.

More angles on the same element:
- atomic number 38 — in a periodic table sorted by Z, Sr is entry #38
- one mole (87.62 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 2.64 g — sample 31 is exactly this cube
- its melting point 777 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
