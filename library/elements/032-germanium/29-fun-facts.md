# Fun facts about Germanium

The first transistor, 1947, was germanium — silicon only took over later.

More angles on the same element:
- atomic number 32 — in a periodic table sorted by Z, Ge is entry #32
- one mole (72.63 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 5.323 g — sample 31 is exactly this cube
- its melting point 938.2 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
