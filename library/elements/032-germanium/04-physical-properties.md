# Physical properties of Germanium

| property | value |
|---|---|
| density (near room temp) | 5.323 g/cm³ |
| phase at 20 °C | solid |
| melting point | 938.2 °C |
| boiling point | 2833 °C |
| appearance | see 09-optical-properties.md — colour #668f8f in this library's palette |

Density is mass divided by volume: a cube of Germanium measuring 1 cm on a side
weighs 5.323 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Germanium is a solid at room temperature; heat it past 938.2 °C and it flows.
