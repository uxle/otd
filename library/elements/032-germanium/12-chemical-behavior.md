# Chemical behaviour of Germanium

Germanium reacts like a textbook metalloid:

- with air: slow surface oxidation
- with water: negligible at room temperature
- with acids: mostly resistant

Electronegativity: 2.01 on the Pauling scale — a measure of how strongly the atom pulls shared electrons.

The octet rule drives everything: atoms react to reach a full outer shell.
Metals lose electrons to become positive cations; nonmetals gain electrons to become anions; the exchange is a salt.
Germanium follows these rules so reliably that Mendeleev used family patterns
like this to predict elements before anyone had seen them.
