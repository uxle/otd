# Physical properties of Titanium

| property | value |
|---|---|
| density (near room temp) | 4.506 g/cm³ |
| phase at 20 °C | solid |
| melting point | 1668 °C |
| boiling point | 3287 °C |
| appearance | see 09-optical-properties.md — colour #bfc2c7 in this library's palette |

Density is mass divided by volume: a cube of Titanium measuring 1 cm on a side
weighs 4.506 g — the 48-molar-volume and 49-density-compare samples
in this folder draw exactly this mathematics in 3D.

Titanium is a solid at room temperature; heat it past 1668 °C and it flows.
