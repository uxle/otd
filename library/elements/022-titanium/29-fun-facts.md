# Fun facts about Titanium

Titanium has the best strength-to-weight of any metal — and it is fully biocompatible.

More angles on the same element:
- atomic number 22 — in a periodic table sorted by Z, Ti is entry #22
- one mole (47.867 g) holds 602,200,000,000,000,000,000,000 atoms
- a 1 cm³ cube weighs 4.506 g — sample 31 is exactly this cube
- its melting point 1668 °C is reached in a furnace
- stable: it has outlived the Earth so far and will outlive us
