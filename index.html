What's new in OTD 6.0

Self-describing

otd --list-all dumps every function, material, keyword, shape, color, and simulate domain — straight from source, never hand-maintained. In-script: functions(), materials(), keywords().

Single-source version

Cargo.toml is the ONE source of truth. --version, the banner, and the phase banner all read env!("CARGO_PKG_VERSION"). No more four different version strings.

Callable electrodynamics

9 functions now usable from scripts: ohm_v(i,r), ohm_i(v,r), ohm_r(v,i), power_vi(v,i), power_ir(i,r), cap_energy(c,v), ind_energy(l,i), rc_tau(r,c), lc_omega(l,c).

Electrical connectivity

connect: A B declares electrical paths. simulate: circuit walks the real resistance of modeled windings (R = ρL/A) and reports current, voltage drop, and power.

Motor simulation

simulate: motor — F=B·I·L, τ=N·B·I·A, back-EMF, stall torque, RPM, efficiency. Delivers the verdict: "WILL IT MOVE? YES ✓"

Expression interpolation

print "{a+b}" now evaluates expressions, not just bare names. Falls back gracefully with a warning if the expression is invalid.

Make a motor, connect it, check will it move

# build the motor
rotor = cylinder(r: 1.5cm, h: 4cm) material: copper
stator_n = cube(2cm) material: iron
magnetize: stator_n
battery = cylinder(r: 1.5cm, h: 5cm) material: lithium

# connect the electricity
connect: battery rotor

# check the circuit
simulate: circuit
# → current: I = V/R = 0.003 A
# → VERDICT: current flows — circuit is closed

# check will it move
simulate: motor
# → stall torque: 0.0565 N·m
# → no-load speed: 6366 RPM
# → ==== WILL IT MOVE? ====
# → YES ✓ — exceeds load by 56.5×
# → The motor WILL spin at 4899 RPM

Constraints we keep, forever

  1. Zero external crates. If a phase needs a library, the phase is redesigned — not the constraint.
  2. Rust + assembly only on the backend; the browser stays a dumb terminal.
  3. < 100 keywords. New capabilities are new words only if the budget allows; otherwise they are parameters.
  4. Old .otd files never break (forward-compatibility policy).
